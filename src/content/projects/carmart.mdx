## Overview

CarMart is an internal tool for a fictional pre-owned car dealership. Employees can list
vehicles for sale, search by owner or model, edit vehicle details, and view the full
inventory stored in the database.

## Focus

The interface stays simple so employees can work with the database without friction, and
vehicle records are shown in a clear, structured layout that's easy to read and update.

The app is no longer hosted; the screenshots and source code show how it worked.
