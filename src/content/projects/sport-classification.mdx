## Overview

Sports are traditionally labeled "collision" or "contact." I led a team of three data
scientists testing that split against survey data on participants' behavior, cognition,
sleep, and concussion history.

## Approach

- Cleaned the survey data, normalized free-text answers, and ran statistical tests to find the sleep and attention features linked to concussion history.
- Used PCA and several clustering methods to look for natural groupings.

## Findings

- A two-cluster solution fit best, which supports the traditional binary classification.
- Sleep features lined up most closely with the conventional labels, especially for football.
- Attention features showed patterns that didn't always match the existing categories.

These results show where traditional labels fall short and how cognitive-behavioral data
could better reflect repeated head-impact exposure. The work sets up future studies using
position-specific and neurological data to improve athlete-safety models.
